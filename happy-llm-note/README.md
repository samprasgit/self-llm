# Happy-LLM 
>从零开始的大语言模型原理与实践教程

## 📖 学习笔记简介

这是我学习大语言模型（LLM）的完整笔记记录，记录了从零基础到实战应用的全过程。我希望通过系统性的学习和实践，深入理解LLM的核心原理，并掌握实际开发技能。这份笔记既是我的学习轨迹，也希望能为其他同学提供参考。

## 📚 课程结构

本课程分为**基础知识**和**实战应用**两大部分，共7个章节：

### 🔰 基础知识部分（第1-4章）

**第1章：NLP基础**
- NLP基本任务介绍
- NLP发展历程概述
- 为非NLP领域研究者提供入门参考

**第2章：Transformer架构**
- Transformer原理详解
- 核心机制代码实现
- LLM最重要的理论基础

**第3章：预训练语言模型（PLM）**
- Encoder-Only架构
- Encoder-Decoder架构
- Decoder-Only架构
- 主流LLM架构思想解析

**第4章：大语言模型概述**
- LLM特点与能力分析
- LLM训练过程详解
- 从PLM到LLM的演进

### 🚀 实战应用部分（第5-7章）

**第5章：从零构建LLM**
- 基于PyTorch手工搭建LLM
- 预训练完整流程实现
- 有监督微调实战

**第6章：Transformers框架实战**
- 业界主流训练框架介绍
- 高效LLM训练实现
- 框架优化与最佳实践

**第7章：LLM应用生态**
- LLM评测方法与工具
- 检索增强生成（RAG）
- 智能体（Agent）设计与实现
- LLM应用开发实战
